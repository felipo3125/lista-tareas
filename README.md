# Task Manager CLI

A command-line task management application built with Python.

The application allows users to create, view and complete tasks while storing all data in a JSON file.

---

## Features

- Add new tasks
- Display all tasks
- Mark tasks as completed
- Persistent JSON storage
- Automatic file creation
- Error handling for missing or corrupted files
- Simple command-line interface

---

## Technologies

- Python 3
- JSON

---

## Installation

```bash
git clone <repository-url>

cd task-manager

python task_manager.py
```

---

## Project Structure

task_manager.py

Main application logic.

tasks.json

Automatically created database storing all tasks.
